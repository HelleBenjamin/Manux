Userland
========

Userland programs makes Manux useful. They are located in the `userland/` directory.
All userland programs are loaded dynamically to fixed address 0x5000.

Programs
--------

Manux ships with so called "built in" programs.
Here's a list of them:
* ecalc - calculator originally written for ELKS
* edit - simple and minimal text editor
* m80asm - small z80 assembler
* shell - default Manux shell
